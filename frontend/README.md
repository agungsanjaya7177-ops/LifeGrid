# LifeGrid Frontend

React + TypeScript + Vite + Tailwind CSS

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Starts the development server at `http://localhost:5173`.

## Build

```bash
npm run build
```

## Type Check

```bash
npm run type-check
```

## Environment Variables

Create a `.env` file based on `.env.example`:

```bash
cp .env.example .env
```

Configure `VITE_API_BASE_URL` to point to your backend API.
